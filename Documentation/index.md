---
title: Direct
description: Public documentation for Direct, the Cratis platform that schedules and governs AI agents working across your repositories, starting with the Direct Agent Runner.
---

Direct schedules AI agents to investigate and implement work across the repositories of your GitHub
organization, and governs how far that work goes. This site documents the parts of Direct that you
install, run or configure yourself.

## Topics

| Topic | What it covers |
| --- | --- |
| [Direct Agent Runner](./runner/index.md) | Run Direct's agents on your own machine instead of the Direct cluster. Install it on macOS, Linux or Windows, connect it to Direct and choose whose work it runs. |

More topics arrive here as further parts of Direct become public.
